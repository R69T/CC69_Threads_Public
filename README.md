# CC69 Threads Manager

CC69 Threads Manager 是一套 Windows Threads 關係管理工具，將常用的追蹤整理功能集中在單一桌面程式中。

## 主要功能

- **快速檢查**：快速取得目前可讀取的 Followers / Following 關係並整理互追狀態。
- **官方完整檢查**：支援匯入 Meta 官方下載的 Threads 資料進行完整比對。
- **沒回追整理**：列出「我有追蹤、對方沒有回追」的帳號，可勾選後依序取消追蹤。
- **新追蹤保護**：可設定保護天數，避免剛追蹤不久的帳號太快被整理。
- **互追中心**：自願加入互追配對，取得尚未配過的帳號並逐一完成追蹤，同一組帳號不重複配對。
- **登入狀態保存**：第一次登入完成並儲存登入資訊後，之後通常不需要每次重新輸入帳號密碼。
- **本機資料保存**：關係整理與操作狀態主要保存在使用者自己的電腦中。

## 使用方式

1. 到 **Releases** 下載最新的 `CC69_Threads_Manager.exe`。
2. 第一次開啟後，到「快速檢查」完成 Threads 登入。
3. 若 Threads 顯示「儲存登入資訊」，請完成該步驟；CC69 會等待登入流程真正完成後再繼續。
4. 依需求使用「快速檢查」、「官方完整檢查」或「互追中心」。

## 下載檔案

- `CC69_Threads_Manager.exe`：Windows 執行檔
- `CC69_Threads_Manager.exe.sha256`：SHA-256 完整性核對檔

## 使用提醒

CC69 不會要求你把 Threads / Meta 密碼輸入到 CC69 本身；登入是在開啟的官方登入頁面中完成。

Threads 網頁介面與平台限制可能變更，因此快速檢查取得的關係資料可能不完整。需要較完整的關係比對時，建議使用「官方完整檢查」。

所有追蹤與取消追蹤操作都應由使用者主動確認後執行；若 Threads 顯示驗證、暫時限制或稍後再試等訊息，請停止操作並稍後再使用。
