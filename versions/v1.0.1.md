# CC69 Threads Manager v1.0.1

本次版本主要整理介面、加入品牌 Logo，並改善互追中心流程。

## 更新內容

- 新增 CC69 正式產品 Logo 與 Windows 應用程式圖示。
- 重新整理整體介面配色、字級、按鈕與 Tab 顯示層級。
- 將「官方完整檢查」改名為「手動下載資訊完整檢查」。
- 檢查結果與「沒回追我」整理只顯示在檢查頁，不再與互追中心混在一起。
- 互追中心移除批次數量設定，改為程式內建處理上限。
- 互追中心新增更清楚的進度顯示。
- 如果配對帳號在加入前就已經互追，可確認後直接記錄為已完成互追，不再視為追蹤失敗。
- 一般 Build 不再上傳 GitHub Actions Artifact，避免 Artifact 儲存配額影響測試與編譯。

## 下載

一般 Windows 使用者請下載本版本的 Windows ZIP，解壓縮後執行 `CC69_Threads_Manager.exe`。
