# CC69 Threads Manager v1.0.0

第一個正式公開版本。

## 主要功能

- 快速檢查 Threads Followers / Following 關係。
- 支援匯入 Meta 官方 Threads 資料進行較完整的關係比對。
- 顯示互追、沒回追我、我沒回追等整理結果。
- 可勾選帳號後依序取消追蹤。
- 支援新追蹤保護天數，避免剛追蹤不久的帳號太快被整理。
- 新增互追中心，可自願加入互追配對並取得尚未配過的帳號。
- 追蹤與取消追蹤都會在操作後確認頁面狀態，再判斷是否成功。
- 第一次登入會引導完成 Threads 登入資訊儲存，之後通常不需要每次重新登入。
- 關係資料與操作狀態主要保存在使用者自己的電腦。

## 使用提醒

Threads 網頁介面與平台限制可能隨時變更。若快速檢查結果不完整，可改用「官方完整檢查」。

若 Threads 顯示驗證、暫時限制或稍後再試等訊息，請停止操作並稍後再使用。
