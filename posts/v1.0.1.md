# CC69 Threads Manager v1.0.1 更新

這次更新主要把 CC69 的介面與互追中心整理得更清楚，也加入正式產品 Logo。

更新重點：
- 新增 CC69 正式 Logo 與 Windows 程式圖示
- 重新整理介面配色、字級、按鈕與分頁
- 「官方完整檢查」改名為「手動下載資訊完整檢查」
- 沒回追整理只會出現在檢查頁，不再混進互追中心
- 互追中心移除使用者批次數量設定，改為程式內建處理
- 新增更清楚的互追進度顯示
- 如果兩個帳號加入前就已經互追，確認後會直接記錄成已完成，不再當作錯誤

下載最新版：
https://github.com/R69T/CC69_Threads_Public/releases/tag/v1.0.1

Windows 使用者請下載 ZIP，解壓縮後執行 CC69_Threads_Manager.exe。
