# CC69 Threads Manager v1.0.0 正式版發布

CC69 Threads Manager 第一個正式公開版本上線了。

這是一套 Windows Threads 關係管理工具，主要功能包括：

- 快速整理 Followers / Following 與互追狀態
- 支援 Meta 官方 Threads 資料匯入比對
- 找出沒回追我的帳號並可勾選後依序取消追蹤
- 新追蹤保護，避免剛追蹤的帳號太快被整理
- 互追中心，可自願加入互追配對並取得尚未配過的帳號
- 第一次登入完成並儲存登入資訊後，之後通常不需要每次重新登入

下載最新版：
https://github.com/R69T/CC69_Threads_Public/releases/tag/v1.0.0

Windows 使用者請下載 `CC69_Threads_Manager.exe`。

如果 Threads 顯示驗證、暫時限制或稍後再試等訊息，建議停止操作並稍後再使用。
